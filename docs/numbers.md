# Numbers

| Number | Cardinal | Ordinal |
| --- | --- | --- |
| 1 | én / ett | første |
| 2 | to | andre |
| 3 | tre | tredje |
| 4 | fire | fjerde |
| 5 | fem | femte |
| 6 | seks | sjette |
| 7 | sju | sjuende |
| 8 | åtte | åttende |
| 9 | ni | niende |
| 10 | ti | tiende |
| 18 | atten | attende |

- **den første dagen** — the first day
- **den andre dagen** — the second day
- **den tredje dagen** — the third day
- **den åttende dagen** — the eighth day

Remember **åttende** (eighth) vs. **attende** (eighteenth).
