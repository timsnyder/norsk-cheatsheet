# Intensifiers (forsterkende ord)

Norwegian uses standalone adverbs and compound prefixes to strengthen adjectives.
**Intensity is not a fixed scale:** meaning, tone, and register matter too.

## Approximate ranking

| Expression | Approximate English | Usage |
| --- | --- | --- |
| ganske | quite / fairly | Mild or moderate; context-dependent |
| nokså | rather / fairly | Usually moderate |
| veldig | very | Neutral and versatile |
| kjempe- | super / really | Informal compound prefix |
| virkelig | really / truly | Emphasizes sincerity or truth |
| skikkelig | properly / really | Conversational and emphatic |
| ordentlig | properly / really | Conversational; also literal “properly” |
| utrolig | incredibly | Strong emphasis |
| ekstremt | extremely | Direct, strong |
| sykt | insanely / crazy | Informal; written separately |
| sinnssykt | insanely | Strong, colloquial |
| vanvittig | unbelievably / insanely | Strong |
| drit- / dritt- | freaking / super | Slang compound prefixes |
| jævlig | damn / fucking | Vulgar and forceful |
| forbanna | damned / bloody | Often angry; not a universal intensifier |

This table is illustrative, **not a measurable intensity ladder**. For example,
*virkelig* stresses truth rather than necessarily exceeding *veldig* in strength.

## One sentence, several shades

- **Du gjorde meg veldig lei meg.** — You made me very sad.
- **Du gjorde meg virkelig lei meg.** — You made me genuinely sad.
- **Du gjorde meg skikkelig lei meg.** — You made me really upset.
- **Du gjorde meg utrolig lei meg.** — You made me incredibly sad.

## Drit- and dritt- compounds

These prefixes can intensify many adjectives, but not every combination is idiomatic.
Both spellings occur; individual compounds may favor one spelling. They are written
**together** with the adjective.

| Norwegian | English |
| --- | --- |
| dritgøy / drittgøy | super fun |
| dritbra | freaking awesome |
| dritfin | really beautiful / nice |
| dritflink | extremely skilled |
| dritredd | scared shitless |
| dritlei | completely fed up |
| dritkaldt | freaking cold |
| dritvanskelig | really difficult |
| dritkoselig | super cozy / lovely |

**Det var dritbra!** — That was freaking awesome!

**Det var dritt!** — That sucked!

The root can intensify something positive in a compound even though *dritt*
by itself is negative.

## Five ways to say “fun”

- **Det var ganske gøy.** — That was fairly fun.
- **Det var veldig gøy.** — That was very fun.
- **Det var kjempegøy!** — That was super fun!
- **Det var utrolig gøy!** — That was incredibly fun!
- **Det var dritgøy!** — That was freaking awesome!

These are examples of tone, not exact numeric intensity levels.

## Sykt and helt

**Sykt** is a separate word in these uses:

- **Det er sykt bra!** — That's insanely good!
- **Hun er sykt flink!** — She's ridiculously talented!
- **Det var sykt gøy!** — That was crazy fun!

**Helt** often expresses completeness, not just high intensity:

- **Jeg er helt enig med deg.** — I completely agree with you.

Here *helt enig* is more idiomatic than *veldig enig*.

## Spelling and register reminders

- **kjempegøy**, **dritgøy**: compounds, written as one word.
- **sykt gøy**, **veldig gøy**, **utrolig gøy**: adverb + adjective, separate words.
- **drit-**, **jævlig**: informal or vulgar; use with care in professional settings.
- **ganske**, **veldig**, **virkelig**: generally safe in ordinary conversation.
