# Vocabulary

| Norwegian | English | Note |
| --- | --- | --- |
| alltid | always | Standard, frequent |
| bestandig | always | Often interchangeable with `alltid` |
| for alltid | forever | Fixed expression |
| å kjenne | to know / be familiar with | People, familiarity |
| kjent | known / familiar | Adjective / participle |
| ukjent | unknown / unfamiliar | `u-` = negative prefix |
| å erkjenne | to acknowledge / admit | Recognition or admission |
| å anerkjenne | to recognize / acknowledge | Also formal recognition |
| anerkjent | recognized / respected | Often describes reputation |
| å prøve | to try | `prøver, prøvde, prøvd` |
| skatt | treasure | Also an affectionate term |
| norsk skogkatt | Norwegian Forest Cat | Standard spelling |
| smør | butter | Neuter noun |
| morsmål | native language / mother tongue | Neuter noun |
| gjennom | through | Preposition |
| videre | further / onward | Adverb |
| frisk | healthy / fresh | Adjective |
| flink | skilled / good at something | Adjective |
| taus | silent | Adjective |
| forvirret | confused | Adjective |

## Word formation

- **kjent → ukjent**: known → unknown.
- **å erkjenne → å anerkjenne**: related verbs with different uses.
- The **aner-** sequence is not a productive Norwegian prefix; `anerkjenne`
  was influenced by German **anerkennen**.
