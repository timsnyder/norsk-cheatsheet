# Norsk Cheat Sheet

A living, source-controlled Norwegian Bokmål grammar and vocabulary reference.

## Contents

- [Grammar](docs/grammar.md) — subjects, word order, articles, and adjectives
- [Verbs](docs/verbs.md) — conjugations, modal verbs, and **å prøve**
- [Phrases](docs/phrases.md) — everyday expressions, including "Are you OK?"
- [Vocabulary](docs/vocabulary.md) — common words and useful word families
- [Intensifiers](docs/intensifiers.md) — emphasis, slang prefixes, and register
- [Confusing pairs](docs/confusing-pairs.md) — similar-looking words
- [Pronunciation](docs/pronunciation.md) — sounds and spelling
- [Numbers](docs/numbers.md) — cardinals and ordinals
- [Validation](VALIDATION.md) — what tests do and do not establish

## Development

Run `python3 scripts/validate.py` to check source structure and curated examples.
Install `mkdocs` and run `mkdocs serve` to preview the searchable reference locally.

All content is editable Markdown. Pull requests are reviewed before merging.
Automated checks cannot certify idiomatic Norwegian; see [VALIDATION.md](VALIDATION.md).
